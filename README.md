# 🎓 Student Performance Prediction

A Machine Learning project that predicts a student's final academic score using study hours, attendance, previous score, and completed assignments.

## 📌 Project Overview

This project uses Linear Regression to predict a student's final score based on academic and study-related factors.

The project also provides an interactive Streamlit web application where users can enter student details and get a predicted final score.

## 🚀 Features

- Predicts student final academic score
- Uses Linear Regression Machine Learning model
- Interactive Streamlit web interface
- Takes study hours, attendance, previous score, and assignments as input
- Displays model performance metrics
- Simple and user-friendly interface

## 🛠️ Technologies Used

- Python
- Pandas
- Scikit-learn
- Linear Regression
- Streamlit
- Git & GitHub

## 📊 Input Features

The model uses the following features:

| Feature | Description |
|---|---|
| Study Hours | Daily study hours |
| Attendance | Student attendance percentage |
| Previous Score | Previous academic score |
| Assignments Completed | Number of completed assignments |

## 🤖 Machine Learning Model

**Algorithm:** Linear Regression

The dataset is divided into training and testing sets. The model is trained using the training data and evaluated on the test data.

## 📈 Model Performance

- **Mean Absolute Error (MAE): 1.04**
- **R² Score: 0.99**

> Note: These results are based on the project's current dataset.
